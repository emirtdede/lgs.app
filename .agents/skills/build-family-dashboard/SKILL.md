# Build Family Dashboard

Respect owner/admin/viewer permissions. Display today/weekly completion, overdue tasks, 30-day consistency, question volume, topic progress, mistake reasons and benchmark trends. Benchmark chart uses exact 20 only and shows accuracy alongside speed. No peer comparison. Admin-only actions include reschedule and resource/plan management with audit. Viewer is strictly read-only. Realtime may update views but correctness must survive refresh without it.

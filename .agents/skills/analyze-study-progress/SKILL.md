# Analyze Study Progress

Use definitions in `docs/11_ANALYTICS_METRICS.md`. Never mix extra blocks with Benchmark 20 speed. Exclude cancelled/flagged attempts. Prevent task/session double-counting. Accuracy denominator is actual question count. Day completion ignores optional reading/rest/meal. Consistency is rolling eligible-day percentage, not fragile streak. Add deterministic fixtures that prove metric outputs.

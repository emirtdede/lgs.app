# UI / Accessibility Rule

Mobile first, Turkish UI, calm and non-judgmental. Student Today page prioritizes the next actionable task. Use semantic native controls, visible focus, keyboard access, labels, error summaries, reduced-motion support and roughly 44px touch targets; target WCAG 2.2 AA. Timer is neutral count-up, never red/countdown. Color never carries meaning alone. Avoid hover-only controls. No horizontal page overflow at 320px. Charts require readable text summaries.

# Core Project Rule

Read `AGENTS.md` and `docs/00_DECISIONS_AND_PRECEDENCE.md` before substantial work. Do not re-ask settled product decisions. Explore existing implementation before editing. Fix root causes, add regression tests, run the relevant quality gate, then continue. Never declare success with failing tests/build/typecheck. Record genuinely new decisions in `docs/DECISION_LOG.md`. Keep user-visible UI Turkish and code identifiers English.

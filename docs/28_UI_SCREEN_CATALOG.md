# 28 — UI Screen Catalog

## Student

### S-01 Pair Device

One code input + device label. No email/phone. Clear expiry/invalid message.

### S-02 Today

Date, completion, next action, daily routines, topic tasks, completed accordion, reading lock/unlock.

### S-03 Benchmark Timer

Routine/topic label, 00:00:00 count-up, Finish/Cancel. No target.

### S-04 Benchmark Result

Exactly 20 split into Doğru/Yanlış/Boş; live sum indicator; submit only when sum=20.

### S-05 Extra Questions

Shows extra count separately; optional count-up may be collected but never feeds benchmark trend.

### S-06 Plan

Calendar/list of own schedule; read-only. Overdue explicitly marked but not shame-colored.

### S-07 Progress

Speed+accuracy trends, question counts, topics, 30-day consistency.

### S-08 Mistakes

Open/reviewed/resolved mistakes; cause and topic filters.

### S-09 Reading

Visible/unlocked only after required day complete; optional timer/pages/title.

### S-10 Profile/Device

Nickname, device session info, sign-out warning that anonymous account can lose access until re-paired.

## Adult

### A-01 Login/Reset

Permanent account flow.

### A-02 Dashboard

Today/weekly summary, overdue, consistency, benchmark trends, topics.

### A-03 Calendar

Plan days, task load, completion; opens day detail.

### A-04 Plan Day Detail

Tasks, source, history; admin reschedule action.

### A-05 Import

Upload → dry-run validation → exact diff → commit button. Commit is owner-only.

### A-06 Analytics

Filters by subject/date; benchmark comparisons preserve exact-20 semantics.

### A-07 Mistakes

Family view of weak areas and review state.

### A-08 Resources

Fixed sources visibly marked. Math/Turkish fixed resources cannot be replaced through ordinary edit.

### A-09 Family/Devices

Members, roles, pairing-code generation, device revoke.

### A-10 Audit

Recent imports, reschedules, role/device changes.

### A-11 Settings

Planning anchor/official exam date update, display preferences, backup status if available.
